Dell Trading Backups

Privacy policy

Effective October 29, 2026 · Maintained by Joe Armani

Purpose and account access

Dell Trading Backups is my personal Windows backup utility. It uses Google Drive to store selected local files and to check that uploaded archives can be downloaded and restored.

The utility requests the https://www.googleapis.com/auth/drive.file permission. It creates a dedicated backup folder, uploads archives and verification records, and reads those files back. It uses folder identifiers, file metadata, hashes, and available account storage to locate backups, check transfers, and decide whether there is room for another upload.

Data stored

Archives contain the configured local files and source code. Their manifests record original file paths, file sizes, hashes, and database snapshot details. Account-pairing records contain the configured account email and a workstation identifier. Local and cloud receipts record backup times and verification results.

Archives and verification records are stored in the Google Drive account authorized by the operator. Temporary archives, downloaded restore copies, and operational logs are stored on the Windows workstation. Google authorization credentials are saved in a local directory protected by Windows filesystem permissions.

Use and sharing

Automated backup runs transfer backup contents and related metadata between the Windows workstation and the authorized Google Drive account. The utility uses that information for backup, verification, and recovery. It does not send backup contents to this public information website, advertising networks, data brokers, or AI training services.

Google API data is used for the functions described here, consistent with the Google API Services User Data Policy, including its Limited Use requirements. Google processes data stored in Drive under its own terms and privacy policies.

Retention and deletion

Cloud archives remain in Drive until the operator deletes them. The utility does not automatically prune cloud backups or delete original source files. After successful verification, it removes temporary local archives and restored copies from that operation. Failed-operation files and diagnostic logs may remain on the workstation for troubleshooting.

The account owner can delete the backup folder through Google Drive and remove local backup records using the workstation’s file tools. Deletion within Google Drive is subject to Google’s trash and retention behavior.

Removing access

The account owner can revoke the utility’s access from Google Account connections. Revocation prevents future authenticated transfers. Existing archives remain in the owner’s Drive account until deleted.

This information website

These pages explain the utility and its policies. The website’s hosting provider may process normal web-request information to deliver the pages and maintain service. Backup files and Google authorization credentials are not uploaded to the website.

Contact and changes

Contact Joe Armani at joe@joearmani.com with questions about this utility or its data handling. Material changes to its Google data use will be reflected in this policy and presented for renewed consent before that changed use begins.
