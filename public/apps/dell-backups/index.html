Dell Trading Backups

Selected files from my Windows computer, backed up to my own Google Drive account and checked by restoring them.

I built this utility to preserve the files and source code used in my trading research. It runs on my Windows workstation. After uploading an archive, it downloads the archive again and restores its files into a separate folder to check file hashes and database integrity.

How it works

  1. The utility copies explicitly configured folders and makes consistent SQLite database copies.
  2. It uploads a versioned archive and its verification records to a dedicated folder in the Google Drive account I authorize.
  3. It downloads and restores the archive locally. A backup is recorded as verified only after those checks pass.

Google account access

The utility requests Google Drive’s drive.file permission and works with the files it creates in its backup folder. It also checks available account storage before uploading. I approve account access through Google’s sign-in screen.

Personal use

Dell Trading Backups is a personal utility I maintain for my own workstation. This website provides app information and policies. The backup itself runs on Windows and stores its archives in the authorized Google Drive account.
